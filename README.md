# DEXPI 2.0 Viewer/Validator

This project is a viewer/validator for DEXPI 2.0 files (with or without DISC DEXPI profile(s)). 

[https://toniapedersen.github.io/DEXPIViewer/](https://toniapedersen.github.io/DEXPIViewer/)

I have included a number of validation rules for both standard DEXPI files and DISC Profile related validation checks.

Check out the DEXPI DISC Example Files folder for the DISC DEXPI blueprint file + profile
